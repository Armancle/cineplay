Project Overview

About CinePlay

CinePlay is a state-of-the-art entertainment recommendations portal. Designed as a comprehensive client-side project, it features a glassmorphic dark theme and a client-side matching engine that recommends content based on user mood, genre interests, release era, and platforms.

Built entirely with semantic HTML5, CSS3 modules, and responsive JavaScript (ES6+), CinePlay utilizes standard LocalStorage queries to support persistent user bookmarking libraries and recently viewed items tracker lists. It runs completely offline without the need for API keys, database servers, or complicated software dependencies.

Key Platform Features

  • Interactive Quiz Recommendation Stepper Engine
  • Advanced Filtering, Keyword Search, & Dynamic Sorting
  • LocalStorage Bookmark Collection Library & Recently Viewed Tracks
  • Persistent Light & Dark Theme Configuration Toggle
  • Mobile Drawer Menus & Sticky Navigation Headers
  • Micro-interactions, Skeleton Screen Loaders, and Image Fallbacks
